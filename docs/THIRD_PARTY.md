# Third-party software and licenses

Verified 15 November 2026 against package.json, package-lock.json, installed package metadata/license files, source imports and vendor manifests. These are project pins, not claims about latest releases. Application software has its own [MIT LICENSE](../LICENSE), copyright 2026 Anjila Gurung. NASA/USGS assets retain separate credits and applicable terms.

## Production software

Original license locations are repository-relative. Build copies are generated by scripts/prepare-public.mjs; deployed paths are relative to dist/.

| Software / version | Purpose | SPDX license | Original local license | Production inclusion |
| --- | --- | --- | --- | --- |
| React 18.3.1 | JSX UI/lifecycle | MIT | `node_modules/react/LICENSE` | Bundled; `licenses/react/LICENSE` |
| React DOM 18.3.1 | Browser rendering | MIT | `node_modules/react-dom/LICENSE` | Bundled; `licenses/react-dom/LICENSE` |
| Scheduler 0.23.2 | React DOM scheduling dependency | MIT | `node_modules/scheduler/LICENSE` | Bundled; `licenses/scheduler/LICENSE` |
| Lucide React 0.468.0 | Interface icons | ISC | `node_modules/lucide-react/LICENSE` | Imported icons bundled; `licenses/lucide-react/LICENSE` |
| Leaflet 1.9.4 | Surface viewport/projection | BSD-2-Clause | `public/vendor/leaflet/LICENSE` | Local JS/CSS/images; `vendor/leaflet/LICENSE` |
| Three.js r160 | Globe geometry/materials/WebGL lifecycle | MIT | `vendor/three/LICENSE` | Lazy Globe bundle; `licenses/three/LICENSE` |

React, React DOM and Lucide are direct package dependencies. Scheduler is React DOM's runtime transitive dependency. The production dependency lock also contains **loose-envify 1.4.0 (MIT)** and **js-tokens 4.0.0 (MIT)**, with licenses at `node_modules/loose-envify/LICENSE` and `node_modules/js-tokens/LICENSE`. They are installed packaging/environment utilities: inspected React/React DOM production entry code imports React/Scheduler, not these utilities. No separate runtime file or license copy for those utilities is emitted by the current preparation script. The lockfile preserves their installed dependency relationship; this is not a claim that every installed production dependency becomes deployed JavaScript.

Leaflet is vendored from the documented 1.9.4 package; no plugin/CDN is used. Exact sizes/hashes and acquisition records are in [DATA_SOURCES.md](DATA_SOURCES.md). Three.js is pinned by [vendor/three/manifest.json](../vendor/three/manifest.json), with exact source URLs, sizes and SHA-256. Its source and MIT license were rehashed against that manifest in this audit. It is rendering software, not planetary data. The deterministic 512 × 256 procedural Globe artwork is project code under the application MIT license and represents no observations.

## Build disclosure paths

The build copies the application license to `public/LICENSE` → `dist/LICENSE`, runtime package licenses to `public/licenses/` → `dist/licenses/`, and preserves Leaflet's license under `public/vendor/leaflet/` → `dist/vendor/leaflet/`. DATA_SOURCES.md, THIRD_PARTY.md and assets/README.md are copied into `public/docs/` → `dist/docs/`. Edit source documents under docs/, not generated copies. No license text, source terms or deployment behavior was changed by this documentation audit.
